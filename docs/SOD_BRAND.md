# Sod prototype identity

## Positioning

Sod is a privacy connection utility for people who should not need to understand subscriptions, protocols, or proxy groups before getting online. The default experience is guided; Hiddify's advanced controls remain available on demand.

The name is provisional. “Sod” means “secret” in Hebrew and is short and memorable, but it has a rude colloquial meaning in British English. Validate it with English-speaking testers and run trademark/domain checks before a public launch.

## Logo

The symbol combines a pomegranate and a shield. The crown and outer silhouette make the pomegranate recognizable; four connected seeds suggest several independent routes forming one protected network. It is deliberately abstract so it reads as a security mark before it reads as a fruit illustration.

## Palette

| Role | Light | Dark | Purpose |
| --- | --- | --- | --- |
| Primary | `#A82448` | `#E45B7D` | Pomegranate, primary actions |
| Background | `#F8F5F2` | `#0B1323` | Warm light / deep ink |
| Surface | `#FFFBF8` | `#151D2C` | Cards and sheets |
| Success | Material semantic green | Material semantic green | Verified connection only |
| Warning/error | Material semantic containers | Material semantic containers | Safety and failures, never branding |

Use semantic Material color roles in code. Red warning strips, neon effects, glass blur, and terminal styling are intentionally excluded.

## Product voice

- Calm, direct, and honest about uncertainty.
- Say “public network” to beginners and keep “proxy”, protocol, and core details in advanced views.
- Never claim that a public route is private, trusted, or verified beyond what the local tests actually prove.
- One primary decision at a time; technical progress remains visible while work is happening and collapses afterward.
